前几天在虚拟机中安装了Ubuntu2604，但系统自带的Bash有些许的辣眼睛。于是，为了以后可以更加优雅的使用终端，今天便决定使用[oh-my-zsh](https://github.com/ohmyzsh/ohmyzsh)对终端进行一下美化。

# 安装
安装zsh

    sudo apt install zsh

设置默认终端为zsh

    chsh -s /bin/zsh

注销并重新登录用户，使更改生效，便会进入配置引导页面，输入`q`退出
![更改生效截图](/assets/img/2026/08-30/01.png)

安装git

    sudo apt install git

安装oh-my-zsh，这里使用国内镜像源

    sh -c "$(wget -O- https://gitee.com/pocmon/ohmyzsh/raw/master/tools/install.sh)"

![安装成功截图](/assets/img/2026/08-30/02.png)

# 配置
编辑`~/.zshrc`文件中`ZSH_THEME`的值即可更改主题，但这里我想尝试使用[powerlevel10k](https://github.com/romkatv/powerlevel10k)主题

国内用户执行如下命令即可完成安装
    
    git clone --depth=1 https://gitee.com/romkatv/powerlevel10k.git "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k"

将`~/.zshrc`文件中`ZSH_THEME`的值改为`"powerlevel10k/powerlevel10k"`

重启终端便会进入配置引导页面

但是为了更好的使用powerlevel10k，我们还需要安装一个新字体[MesloLGS NF](https://github.com/fontmgr/MesloLGSNF)

~~切换到`/usr/local/share/fonts`目录，执行如下命令完成字体安装，这里依旧使用的国内镜像源~~（这里有一些问题，下方的命令**请勿参考**，具体见下文）

    sudo wget -O "MesloLGS NF Regular.ttf" "https://gitee.com/keyboardkiller/MesloLGS_NF/blob/master/MesloLGS%20NF%20Regular.ttf"
    sudo wget -O "MesloLGS NF Bold.ttf" "https://gitee.com/keyboardkiller/MesloLGS_NF/blob/master/MesloLGS%20NF%20Bold.ttf"
    sudo wget -O "MesloLGS NF Italic.ttf" "https://gitee.com/keyboardkiller/MesloLGS_NF/blob/master/MesloLGS%20NF%20Italic.ttf"
    sudo wget -O "MesloLGS NF Bold Italic.ttf" "https://gitee.com/keyboardkiller/MesloLGS_NF/blob/master/MesloLGS%20NF%20Bold%20Italic.ttf"

**在这里讲一个我遇到的问题**

在安装了字体之后，我发现怎样都无法在终端的首选项里找到新安装的字体，这一步卡了我很久，直到我使用`file`命令检查了获取到的文件
![file命令截图](/assets/img/2026/08-30/03.png)
啊哈！我获取到的居然是一个HTML文件，难怪系统无法识别到。可能是因为网络连接不稳定，或`wget`没有处理好重定向导致了这种情况，因为我比较菜，具体原因也不是很清楚QAQ

现在我们已经知道了使用`wget`会出现问题，那么就让我们换一种方式吧。

回到`#`目录，执行如下命令，将gitee仓库拉取到本地

    git clone https://gitee.com/keyboardkiller/MesloLGS_NF.git

现在我们再来用`file`检查一下，可以看到输出有“TrueType Font data”，这正是我们所期望的，哦耶！
![file命令截图2](/assets/img/2026/08-30/04.png)

接下来只需要让系统识别到我们新安装的字体文件即可。之前我试图将字体文件安装到系统目录，这需要进行提权，可能会略有不妥。那么这次我们就将字体安装到用户目录吧。创建`~/.local/share/fonts`目录，将我们得到的4个字体文件复制到其下。

    mkdir ~/.local/share/fonts

    # 将以“MesloLGS NF”开头的文件复制到新目录
    mv MesloLGS\ NF\ * ~/.local/share/
    
使用`fc-cache -fv`更新字体缓存，重启终端，便可在首选项中看到MesloLGS NF字体。换成新字体后，我们终于可以回归正文了！

进入powerlevel10k的配置引导页面，如果一切正常的话，会在中间看到一个菱形，接下来跟着引导一步步来就可以完成配置。
![powerlevel10k配置引导页面](/assets/img/2026/08-30/05.png)

这里我跟随引导完成了基础的配置，但是我还希望终端中可以显示用户名和主机名。要实现该功能，需编辑`.p10k.zsh`文件，在`typeset -g POWERLEVEL9K_LEFT_PROMPT_ELEMENTS=`中添加`context`，并注释掉藏在后文中的`typeset -g POWERLEVEL9K_CONTEXT_{DEFAULT,SUDO}_{CONTENT,VISUAL_IDENTIFIER}_EXPANSION=`
![p10k更改1](/assets/img/2026/08-30/06.png)
![p10k更改2](/assets/img/2026/08-30/07.png)

最后执行`source ~/.p10k.zsh`即可

至此，我们终于完成了终端美化~~~
![美化结果](/assets/img/2026/08-30/08.png)
